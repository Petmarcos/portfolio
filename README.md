# 🚀 Marcos | Portfólio Dev & Hub de Microaprendizagem

Portfólio web moderno e interativo desenvolvido para apresentar meus projetos de desenvolvimento front-end, aplicações full-stack e soluções mobile, além de contar com um ecossistema integrado de microaprendizagem (*Microlearning Hub*).

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias modernas de mercado para garantir alta performance, responsividade e experiência de usuário fluida:

* **HTML5 & JavaScript (Vanilla)** — Lógica e interatividade dinâmicas.
* **Tailwind CSS** — Estilização moderna baseada em utilitários, com suporte a modo escuro e design responsivo.
* **Google Fonts** — Tipografia profissional (*Poppins* e *Montserrat*).

---

## 📱 Projetos em Destaque

O portfólio destaca aplicações reais desenvolvidas e publicadas:

1. **Capigenda:** Agenda pessoal segura com autenticação, segurança RLS e persistência com Supabase. ([Acessar App](https://agendamapa.netlify.app/))
2. **MathManager:** Gerador inteligente de exercícios e plataforma full-stack para professores. ([Acessar App](https://math-manager.vercel.app/))
3. **Capivara Learning:** Validador inteligente de diplomas com cruzamento de dados e-MEC. ([Acessar App](https://automatiza-publicacao-diplomas.vercel.app/))
4. **CapybaraPlayer:** Player de mídia nativo de alta performance para Android desenvolvido em Kotlin. ([Baixar APK](./download/capybaraplayer-v1.apk))

---

## 💡 Recursos do Portfólio

* **Design Responsivo Avançado:** Layout adaptado e otimizado tanto para desktops quanto para telas de dispositivos móveis, com bordas acentuadas e excelente contraste no tema escuro (*Zinc*).
* **Microlearning Hub (Pop-up Interativo):** Um espaço dedicado à aprendizagem rápida estruturado em abas dinâmicas:
  * **Pílulas:** Conceitos rápidos de programação com exemplos de código comentados.
  * **Vídeos Curtos:** Atalhos para pílulas em formato *shorts*.
  * **Quadrinhos:** Histórias ilustradas e bem-humoradas sobre o cotidiano de desenvolvimento.
  * **Quiz:** Desafios práticos para testar o conhecimento.
* **Menu Mobile Otimizado:** Navegação fluida para acesso rápido a todas as seções.
